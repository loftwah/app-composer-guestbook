These 96x96 WebP derivatives come from the reviewed ink-line cel animation tiles in https://github.com/loftwah/app-composer/tree/main/public/brand/apps, exported at the same time as each app's own hero art. Copyright and usage follow the parent MIT repository. No vendor UI and no personal images.

Current set: `herethere-small-20261018`, `linkarooie-small-20261018`, `linkcheck-small-20261018`, `hello-small-20261018` and `carryforward-small-20261018`. Each file uses its own app’s selected optical identity, derived from its existing illustrated world. The switcher keeps every application recognisable.
