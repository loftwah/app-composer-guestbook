Navigation crops for the app switcher, reviewed 17 October 2026. These 96x96 WebP derivatives come from the reviewed ink-line cel animation tiles in https://github.com/loftwah/app-composer/tree/main/public/brand/apps, exported at the same time as each app's own hero art. Copyright and usage follow the parent MIT repository. No vendor UI and no personal images.

Current set: `herethere-small-v4`, `linkarooie-small-v4`, `linkcheck-small-v4`, `hello-small-v4` and `carryforward-small-v4`. Each file is cropped from its own app's illustration so the switcher matches the tile a visitor clicked; none is a generic icon and none is another app's character art.

Removed in earlier artwork releases: the 14 October 2026 `guestbook-small-v1/v2`, `showcase-small-v1/v2`, `linkcheck-small-v1`, `hello-small-v1` and `state-small-v1` crops, and `creators/linkarooie-kangaroo-v1.png`. They came from the earlier mixed set and stayed only while the apps still referenced them. The superseded 17 October 2026 cut-paper crops were removed with the ink-line cel animation release. The bytes remain in this repository's git history.
