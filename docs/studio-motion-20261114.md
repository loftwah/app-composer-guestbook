# Here / there project plate in motion

The public home page includes a fictional illustration, separate from the guestbook's approved submissions. It was made in Media Studio from the retained Woodhouse Share Here / there project plate; no guest submissions were used. [View the original Studio publication](https://media.loftwah.com/p/i0q2jGofhv2yu6m2).

Here / there serves its own copy so playback does not depend on Media Studio. The original Studio MP4 (SHA-256 `d0a87dda0ae2f648b851f2de7d5e1a4c8a492ecc950d75598366c3782591fb1b`) was cropped to the upper 896 × 498 pixels to remove the original's distorted text panel, re-encoded as H.264, and stripped of audio. The resulting five-second silent MP4 has SHA-256 `446b4d31f648dcac2787f82a8233b1573b3f2a8eb04caecec5940ae5d1e00109`. Its first frame was resized to a 768-pixel-wide WebP poster, SHA-256 `699454050edb210f4bbd3d7ceab45b24b93c30ed916c535f6b315c0485f6d1e1`. The complete original remains available at the Studio publication linked above.

The film is labelled as fictional, does not autoplay, has a text description and is not stored in or presented as a guest contribution.
