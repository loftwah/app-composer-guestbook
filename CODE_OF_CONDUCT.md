# Code of conduct

Welcome contributors of every background, identity, ability and experience level. Ask questions, explain decisions clearly, and give people room to learn. Critique the work with specific evidence; treat the person with respect. Documentation, testing, design, accessibility and helping others are contributions too.

Harassment, discriminatory language, threats, unwanted sexual attention, publishing another person's private information, spam and deliberate disruption are unacceptable. This applies in project issues, reviews and other spaces representing this project.

Maintainers may remove harmful content, limit participation or ban accounts when necessary, considering context and repeated behavior. Report a problem privately to repository owner [loftwah](https://github.com/loftwah); if a private channel is needed, request one without posting sensitive details. GitHub's own abuse-reporting tools are also available. Reports should be handled discreetly and without retaliation.

Reviewed 13 October 2026. This is this project's conduct policy; it does not claim endorsement by another community.
